# 🎮 Party Game - Installation PWA

Votre application est maintenant prête pour être installée en PWA sur iPhone !

## ⚡ Prochaines étapes

### 1️⃣ Installer les dépendances

```bash
npm install -D vite-plugin-pwa@^0.17.4
```

### 2️⃣ Générer les icônes

1. Ouvrez `public/icon-generator.html` dans votre navigateur
2. Téléchargez toutes les icônes
3. Placez-les dans le dossier `public/`

### 3️⃣ Tester en local

```bash
npm run dev
```

Ouvrez http://localhost:5173 sur votre iPhone avec Safari et testez l'installation !

### 4️⃣ Build pour la production

```bash
npm run build
npm run preview
```
